## 两个独立决定

- 证据合并：接纳 / 仅接纳方案 / 仅归档无效或中止记录 / 拒绝；原因。
- 基线晋升：不申请 / 拒绝 / 开发候选 / 晋升；合法性、同合同对照、事前指标/不确定性/风险护栏证据；默认版本是否改变。
- 更新了什么理解；首选、次选、暂不投入及理由。纯文档可写“无研究结论变化”。
- 合并方式与远端核对：PR或本地--no-ff；最终main SHA在合并后记录于PR/交接信息，避免自引用；是否保留运行标记和外部产物。
