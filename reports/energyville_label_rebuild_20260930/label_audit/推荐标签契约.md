# EnergyVille 标签独立核验与契约（2026-09-30）

管理者摘要：建议主目标采用记录行程的电池端净电支出，温度不作为标签有效性的门槛。1396个驾驶文件全部保留；1375个通过计数器边界工程筛选，1335个另有同区间IV一致性证据。BMS驱动计数器几乎等于驾驶总放电，而且静止时仍增长，不能据此宣称分离了纯牵引和空调。优先修正数据边界、重复与输入可用性，保留驱动/再生分量作机制候选。

## 1. 本轮做了什么、学到了什么、因此怎么选

已独立读取发布的全部2310个会话CSV（驾驶1396、停车780、慢充109、快充25），读取错误为0。保留原ZIP、逐文件SHA256和全部候选，不运行作者脚本，也不训练模型。每个候选均保存计数器真实端点、名义窗口、端点年龄、原记录漏边时间、缺口、量化尺度、IV交叉证据和拒收/复核原因。温度完全不参与标签筛选。

重要发现不是“标签越细越好”：驱动/再生计数器以多路复用方式广播，端点比总充/放电更晚出现、也更早结束。驱动计数器在驾驶文件静止区间大量增长，其含义不能直接等同轮端机械功或已排除HVAC的纯电驱支路能量。主目标因此采用数据最能支持、业务意义明确的电池端净电支出，而把细分计数器留在机制研究层。

本报告的1375/1335是独立标签工程筛选数，仍须与数据重建输出合并，处理模式归属、重叠、路线覆盖和行程边界。它们不是最终训练样本数，更不等于经过外部电表验证的完整ON/OFF行程真值。

## 2. 能量边界、单位与计算式

下列信号直接从发布DBC静态核验，累计量单位均为kWh、解码刻度为0.001kWh。所有差值保持符号，不取绝对值，不对残差clip。

| 代号 | 发布信号 | 实际可支持的含义 |
|---|---|---|
| D | TotalDischargeKWh3D2 | DBC注明Lifetime Discharge，电池累计放电 |
| C | TotalChargeKWh3D2 | DBC注明Lifetime Charge，电池累计充入，可能包括回收和外部充电 |
| T | BMS_kwhDriveDischargeTotal | BMS按drive归类的累计放电；厂商未提供本项目可核验的支路/功率分配定义 |
| R | BMS_kwhRegenChargeTotal | BMS按regen归类的累计回收电能 |
| V、I | BattVoltage132、RawBattCurrent132 | HV电池电压、电流；已解码电流正为放电、负为充入 |
| BMSdissipation312 | Battery Dissipation，kW | 电池耗散功率信号，不等同HVAC用电 |

V刻度为0.01V；I解码因子−0.05、偏置822A，已经在CSV解码，不能再次套VED的符号。计数器为32bit unsigned，2³²−1对应4294967.295kWh，本审计将该哨兵值排除。来源：发布DBC第2354–2378、2636–2640、2801–2805行及信号注释。

推荐主标签：
E_battery_net = ΔD − ΔC，单位kWh。在排除外部充电的驾驶记录中，C与R接近，目标回答“完成这段记录行程，电池净支出了多少电能”。它直接服务行程电量预算和续航估计，并不保证能够只凭当前行前输入精确预测。

并列辅助标签：ΔD（总放电）、ΔC（总充入）。在无外充记录中，ΔC可作为回收相关分量，但不把所有C机械命名为regen。它们用于解释净值由怎样的放电/回收平衡构成。

保留候选：ΔT、ΔR、ΔT−ΔR、ΔD−ΔT。ΔT−ΔR名为“BMS驱动归类净分量”，允许真实负值；ΔD−ΔT名为“非drive归类放电残差”。这两个名称都不能升级为“纯牵引能量”“单独HVAC能量”，也没有独立轮端/电机功率真值证明其物理边界。

## 3. 为什么不用强制同时有值的行

总充/放电信号同帧，驱动/回收信号多路复用，后两者往往不共享有效行。要求四列同时有值会制造人为样本损失。本审计不插值计数器：

1. 单分量取该计数器首末实际观测。
2. 组合分量声明公共名义窗口：各计数器首次观测时刻的最大值，到末次观测时刻的最小值。
3. 在两个名义边界，只使用已经出现的观测（causal as-of）。
4. 逐计数器保存实际采样时刻和age；名义窗口不代表各计数器测量完全同步。
5. 保存原记录前后未覆盖秒数与这些边缘上可观察的绝对IV电能。该电能只是发布信号诊断，不是未知秒内瞬态的严格物理误差上限。

字段 *_window_start_utc/*_window_end_utc 是计算归一轴。源Timestamp的logger真实时区尚未被证明，utc=True不是时区认证。相对时间、能量积分不依赖恒定时差；与天气、小时/白天等信息连接前必须确认真实时区。

所有1396驾驶文件中的四个计数器均至少出现一次，全驾驶计数器未发现逆行或复位；其中T有4个文件、R有3个文件只出现一次，不能做该分量差值。

strong_internal_candidate只是工程层规则：时间轴有效，累计量单调、未出现明显分量矛盾，原记录无>60s缺口，计数器实际首末覆盖距源记录边界不超过5s，未发现外充/需要模式重建证据。5s是可复核的工程容忍，不是自然定律，也不是测量精度上限。18个驾驶文件有>60s缺口；10个有C−R>0.02kWh的外充归属证据（与缺口可重合），需要模式重建。不能因为计数器能跨缺口计算就宣称缺口属于同一完整行程。

净支出strong 1375：BEV1 378，BEV2 997；≥10km分别207和302。1335个strong另有同名义窗口的IV覆盖≥99%，且全部通过 |E_IV−E_counter| ≤ 0.02kWh + 0.03|E_counter| 的一致性工程规则，分别BEV1 368、BEV2 967。这个规则用于发现冲突，不能宣称标签绝对误差≤3%。

计数器首值延迟：D/C中位数1s、p95 3s；T/R中位数7s、p95 12s。组合T−R的端点异步中位数和p95为11s；源记录末边未覆盖中位数17s、p95 22s。它因5s规则为0个strong，说明默认整程边界假设不适配多路复用，不说明1392个观测窗口毫无价值。所有窗口在 observed_counter_window_labels.csv 保留，可用于声明精确区间的机制研究；不把窗口目标冒称原完整行程目标。

## 5. 量化、短行程与IV交叉验证

DBC刻度q=0.001kWh。无法确认内部舍入规则时，采用每端最多q的保守量化包络：单计数器差2q=0.002kWh；两个计数器相减4q=0.004kWh。其相对量级必须除以 |E_label|，不是除以总放电或人为加epsilon。零值不报告有限相对误差。

净值0.02kWh时，单量化包络就相当于20%；0.08kWh时为5%；1kWh时为0.4%。1375个净支出strong中，1336个满足 |E|≥0.08kWh 的量化5%工程条件。这不要求删除小行程：所有数据保留，近零量用绝对kWh指标和不确定性分层，不主用MAPE。量化包络尚未包含异步、边缘漏能、传感器标定及发布重采样误差。

IV积分只积相邻0<dt≤2s且V/I有效的区间，不跨大缺口。同窗净支出IV−counter差：中位+0.002686kWh、p95 +0.024098kWh，范围−0.011320至+0.143573kWh。两种读数都来自同车CAN，属于内部一致性证据，不是独立电表校准。

分开对IV的正/负部分积分与累计D/C相比，差值中位约−0.0211/−0.0226kWh，净量反而更接近。这与1s平均会掩盖秒内放电/回收往返相容；均值V×均值I也不必等于均值(VI)。这是机制解释，不能凭它证明所有差异来源。故总放电/总充入优先采用累计counter，不把已平均电流的正负积分作为更准确的真值。

## 6. 对“驱动”“辅助”解释的实物审查

分别取各计数器天然首末时刻的T/D仅是诊断：中位0.99085；不应用这个比值直接论证分量机制。按ΔD−ΔT公共/as-of窗口重新对齐后的T/D中位0.994426，p05 0.88424、p95约1。

1392个公共窗口中，153个D/T差完全相同，424个差在±4Wh量化包络内，615个在±10Wh内；566个正残差>20Wh。不存在低于−4Wh的残差；两条−4Wh按量化/同步容差保留原值，未clip或因浮点误判删除。

停车780个文件中，T合计0.046kWh、D合计298.284kWh，只有2个T增量>10Wh；慢充109/快充25个文件T差值全部0。另有512驾驶文件出现1964个60s区间，速度≥90%可观测且全0，其中1917个T增长≥5Wh。这支持T按驾驶相关状态归类，也明确不等于轮端机械功；其增长仍可能涉及驻车扭矩、逆变器损耗、附件负荷或状态分配，不能认证纯电机支路。

论文P22逐程效率示例使用D−R；Fig15生命周期辅助余量用总D−T。论文没有独立验证逐程T排除HVAC。两年非驾驶状态耗电量不能据此变成每次驾驶的可辨识空调标签。因此：保留分量比对用于寻找信息缺失/机制问题，不把残差改成主监督目标，不声称换成T就解决热负载。

## 7. 接下来最有信息价值的工作

首选：与重建表连接，确认真实运动、外充归属、重复、路线和计数器窗口边界，形成全源分层行程表；净电池能量主监督、D/C辅助。输入能否行前获得是另一份合同，标签可信不证明输入足够。

第二候选：在明确的观测窗口上分析T/R与D/C差别，以及在静止、低温、预热和充电后的分配规律。它能检验我们能否实际分离机制，支持研究任务重定义；不承诺得到独立HVAC。

当前不值得：直接把D−T当“空调能耗”，或为提高样本数把5s边界规则静默放宽、把短程净值取绝对值、用平均IV正负积分取代counter、丢弃无首行温度的文件。

- all_mode_label_audit.csv：全会话2310行。
- observed_counter_window_labels.csv：2310×8=18480候选，保留可用/缺失状态，不筛掉原文件。
