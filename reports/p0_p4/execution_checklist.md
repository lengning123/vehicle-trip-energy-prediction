# P0–P4 执行清单与七项论文增强对照

更新时间：2026-09-20。本文件记录实验的预注册口径；指标完成后写入同目录正式报告。

## P0：协议与实现可信度

- [x] 路线距离改为 GPS 匹配几何距离，不再积分真实未来速度。
- [x] 温度只取出发时可观测值，整程平均温度仅保留为标签侧诊断量。
- [x] trip、vehicle、route、time 四种互斥协议。
- [x] 车辆历史严格按时间构建，只使用当前行程之前的数据。
- [x] 变长序列归一化不依赖 padding，加入 padding-invariance 测试。
- [x] 长尾标签、折间交集和样本数自动审计。

## P1：公平且有强度的基线

- [x] 固定 Wh/km、校准物理模型、Ridge、HGB、ExtraTrees、LightGBM。
- [x] A12 物理残差（部署态路线规则工况）。
- [x] G10 Tesla 行程能耗方法（两阶段与直接路径）。
- [x] G04 路线序列方法最终指标。
- [x] 所有部署态方法禁止输入实际未来速度、持续时间、电流、电压和结束 SOC。

## P2：路线工况与车辆历史增强

- [x] 25/50/100 m 路段分辨率消融。
- [x] 车辆历史有/无消融。
- [x] 平均速度、速度平方、时长、正负速度平方变化的多任务监督。
- [x] 历史序列注意力与随机 K 截断训练。
- [x] 质量、滚阻、风阻、附件功率、驱动效率和再生效率的历史条件化。

## P3：双路径与融合优化

- [x] 直接路径、机理残差路径、可学习门控三种训练。
- [x] LayerNorm 与 masked GroupNorm 消融。
- [x] 固定融合权重在验证集选取，并与可学习门控比较。
- [x] 预测工况、规则工况、Oracle 工况三级误差分解（分别训练，避免分布错配）。

## P4：稳健性、泛化与不确定性

- [x] trip-disjoint 五随机种子，报告均值、标准差和置信区间。
- [x] vehicle-disjoint 五折。
- [x] route-disjoint 五折。
- [x] 时间外推。
- [x] 新车辆 0/1/3/5/10 条历史 few-shot 曲线。
- [x] 90% 归一化 conformal 区间覆盖率与宽度。
- [x] 距离、温度、道路密度、历史量分场景误差。

# 七项内容逐项对照

## 1. 先把实验协议做成论文贡献的可信基础

对应 P0。输出协议审计 JSON、泄露黑名单、互斥性检查和 padding 不变性测试。

## 2. 把五个复现实验转化为设计证据

对应 P1。A1、A2、A12、G10、G04 不只比较单一指标，还提炼其输入假设、可部署性、误差来源和可复用模块。

## 3. 提升路线工况表示，而不是偷看真实未来工况

对应 P2。用固定空间路段、多任务工况头和分辨率消融验证信息粒度；Oracle 只作为上限。

## 4. 个性化要来自时间合法的车辆历史

对应 P2/P4。比较无历史、完整历史以及新车 K-shot；不使用 VehId embedding 作为主结论。

## 5. 双路径融合必须证明缓解误差传播

对应 P3。比较 direct、mechanism、learned gate 和验证集选择的 fixed gate；通过三级工况实验分离速度误差与能耗头误差。

## 6. 扩展实验要覆盖真实部署边界

对应 P4。除随机行程划分外，增加新车辆、新路线、时间外推、少样本校准和不同场景切片。

## 7. 报告统计稳定性与预测可信度

对应 P4。五随机种子、五折、均值±标准差、90% 区间覆盖率和区间宽度共同报告，避免只展示单次最优值。
