# EV-B01 运行与交付说明

正式数据准备、模型拟合及保存模型重放均在既有AutoDL实例的`/root/autodl-tmp`执行。E5没有启动。云端已有`completion.json`，无需再次运行训练。

源脚本在项目`scripts/`，合成测试在`tests/test_energyville_evb01.py`。运行环境版本见runtime.json；准备代码使用pandas≥2的显式纳秒API。模型joblib应在匹配的sklearn1.9.1环境加载，本地旧sklearn不能保证兼容。

如需在另一个**新实验目录**重现（不要覆盖本轮）：

```bash
cd /root/autodl-tmp
/root/miniconda3/bin/python tests/test_energyville_evb01.py
/root/miniconda3/bin/python scripts/energyville_evb01_data.py --data data/energyville_evb01_r05 --todo data/energyville_evb01_r05/todo.md --out reports/energyville_study/EVB01_replay
/root/miniconda3/bin/python scripts/run_energyville_evb01.py --out reports/energyville_study/EVB01_replay
/root/miniconda3/bin/python scripts/verify_energyville_evb01.py --out reports/energyville_study/EVB01_replay --models
```

这里只说明复算方法，不授权或自动启动追加拟合。原始todo输入快照位于todo_input_snapshot.md，执行后的当前todo及研究四文件另保存在research_context_snapshot/。protocol_frozen.md和execution_manifest保留拟合前合同，不因本轮结果改写。源代码SHA匹配检查、输出路径映射、模型和指标校验均有JSON证据。

模型为model_R/S/H/O.joblib。B0无需权重文件，训练期每车率在preprocessing_manifest.json。features.csv不是任意主表列的直喂缓存：白名单、各特征公式和可用时点见feature_columns/feature_contract，Oracle单独隔离。predictions_train/validation/future.csv可复算全部指标；无calibration预测文件。

主阅读入口为EVB01_实验报告.md。EVB01_训练时自动报告.md是原始自动解释，最终主报告补充分车、长程及区间证据，纠正了将未来微小正点差当作稳定泛化的表述；report_revision.json保留原哈希。模型、标签、划分、预测、验证决定和指标没有改变。completion.json形成时日志还会打印末行，所以training.log哈希可变化，独立验收明确将它视作动态日志例外，其他冻结文件全部匹配。

本地verification_local.json复算390项指标，云端verification_cloud.json另验证四模型的验证样例重放。两图已经视觉检查。delivery_manifest.json是最终交付文件哈希，排除自身；后续更新报告须保留修订记录，不改它所代表的训练版本。
